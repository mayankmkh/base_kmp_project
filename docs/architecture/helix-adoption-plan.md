## 5. Execution phases (29.5)

1. build-logic: role plugins, validator, policy/exception files, plugin tests.
2. Foundation/platform/storage/ui moves plus new `:foundation:resource`, `:foundation:presentation`, `:foundation:runtime`.
3. `:capability:posts-api/-impl` + `:feature:posts` reference slice; delete `arch:core`, old features, `libs:posts`.
4. `:app:*` composition root and shells; iOS script path.
5. Control plane P0: `tooling/helix-kmp`, `AGENTS.md`, Skills, docs, adoption record; P1 thin commands only if time allows.
6. Verification: `./gradlew check`, debug assembles, iOS framework link, web bundle; evidence report (22.13).
